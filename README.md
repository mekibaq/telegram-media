# mekiba Telegram media

Public media used by the official mekiba Telegram channels: the portal and welcome videos, the sticker set and the custom emoji pack.

- `portal.mp4`, `portal.jpg`: pinned post in the mekiba portal (t.me/mekibaq)
- `welcome.mp4`: welcome message in the mekiba community
- `s01` to `s12`: sticker set (512x512 PNG)
- `e01` to `e11`: animated emoji pack (100x100 WEBM)
